A small, fully crossed calibration

Each of three authored personas—Maria, Frank, and Ruth—receives each of eight situation–consideration pairs under four journal contexts. Three repeats reuse exactly the same text.

4 Honesty targetsAsk whether Honesty supports or opposes the specified action.

The seeded journal asserts an honesty-absolutist conviction. The quoted version attributes the same assertion to someone else without adopting it. Neutral and repeat are identical.

These are eight authored anchors. Repeated calls are duplicate measurements, not independent simulations or sampled people.

Why check batches?

The predeclared gate compared serial and batch-two execution: max |Δp| ≤ 0.01, relative vector L2 ≤ 0.02, cosine ≥ 0.999, and no changed A/B classifications. The check measures both batching and execution-path differences; the Llama failure’s cause is unresolved.

The two-GPU parallel launcher exists. Concurrent two-GPU throughput was not measured in these completed calibrations.

Proposed future study · not run in this pilot

Reuse the measurement after social exposure

Seeded agent→Shared board→Recipient journal→Same battery

First validate the readout. Then compare recipients in matched seeded and unseeded simulations, with a true pre-seeding baseline and follow-up after the original message leaves the feed.

What extra evidence would this need?

Check paraphrases, answer mappings, lexical exposure, and a separate value-prioritization measure. For transmission, pair simulation arms and analyze recipients rather than treating individual calls as independent runs. For persistence, specify what external journal memory remains and measure after neutral turns. The current engine’s round-zero checkpoint is after seeding; a true pre-seeding checkpoint must be added.

Interpretation boundary: the pilot demonstrates context-sensitive readouts. Quotation and answer mapping also move scores. It does not establish moral adoption, persistent change, or agent-to-agent contagion.
